The final prompt set requested a precise removal edit on each reference: remove the embedded “nolii” wordmark and any written slogan; reconstruct the underlying background; preserve Noli's identity, pose, expression, objects, framing, warm palette and lighting; keep the complete scene and original aspect ratio; introduce no new text, watermark or decorative objects. Each scene was edited independently and visually checked.

Text shown beside these images belongs to the Serbian and English translation catalogs, so the selected language also changes the captions. The About page uses making scenes and a jewelry moment. The Noli world section uses self-care, jewelry and candle scenes with gentle descriptions. The login uses `noli-kindness.png`.
